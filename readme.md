# 🎰 Lucky Jet Expert Bot – by gagnant-pro

Un bot Telegram intelligent pour prédire les multiplicateurs du jeu Lucky Jet.

## 🚀 Commandes

- `/start` → Message d’accueil
- `/predict` → Prédiction aléatoire
- `/stop` → Arrêt des alertes

## ⚙️ Installation

```bash
git clone https://github.com/gagnant-pro/luckyjet-bot.git
cd luckyjet-bot
pip install -r requirements.txt
export BOT_TOKEN=ton_token
python bot.py
